# HarderCombatMod


5× enemy base damage for supported attacks and projectiles.
2× enemy health where health is controlled by supported enemy resources.
3× enemy movement speed for supported movement parameters.
3× attack movement and projectile speed where supported.
98% shorter waits between attacks for supported attack intervals.
Expanded behavior adjustments for enemies, bosses, and minibosses, including longer target memory, increased detection and ally alert ranges, and changes to existing guard, evasion, and action-switching parameters.
Additional attack timing changes for Deku Scrubs.
